I made the new project named 'topcourses' where the user can see the courses of there own interest by switch on the navigation bar.
The navigation Bar contain the 5 button:
       1. All (That contain all the courses)
       2. Development (Where all development courses are available)
       3. Business (For business courses)
       4. Design (For design courses)
       5.Lifestyle (For lifestyle courses)
I have integrated the Liked button on every courses, so that the user can like there favourite courses.
I have also added the "React Toast" for the like button that mean when ever user add or remove the favourite courses from like list, then the toaster will appear at the right side of the screen.

For making this interactive WebPage I have used the React.
Where I learned to use the React and write the HTML like code in React , also to write the CSS code.
The aim from this project is to learn the React Basic.
